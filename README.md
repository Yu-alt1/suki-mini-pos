# Suki Mini POS

เว็บแอปพลิเคชัน Static สำหรับร้านสุกี้ขนาดเล็ก ช่วยให้พนักงานรับออร์เดอร์ดูเมนู เพิ่มสินค้าลงตะกร้า ตรวจสอบราคารวม และล้างตะกร้าได้ในหน้าเดียว

**เว็บไซต์ที่เผยแพร่:** https://yu-alt1.github.io/suki-mini-pos/

## คุณสมบัติ

- แสดงเมนู 3 รายการพร้อมราคา
- เพิ่มสินค้าเข้าตะกร้า และเพิ่มจำนวนเมื่อกดสินค้าเดิมซ้ำ
- แสดงรายการสินค้าและจำนวนในตะกร้า
- คำนวณราคารวมจากราคาต่อหน่วยคูณจำนวนโดยอัตโนมัติ
- ล้างสินค้าทั้งหมดและตั้งราคารวมกลับเป็น 0 บาท
- รองรับการใช้งานบนมือถือ

## เมนูและราคา

| เมนู | ราคา |
|---|---:|
| ชุดหมู | 199 บาท |
| ชุดเนื้อ | 249 บาท |
| น้ำดื่ม | 20 บาท |

## วิธีใช้งาน

1. เปิดไฟล์ `index.html` หรือเว็บไซต์ที่เผยแพร่
2. กดปุ่ม **เพิ่ม** ของเมนูที่ลูกค้าต้องการ
3. ตรวจสอบรายการ จำนวนสินค้า และราคารวมในตะกร้า
4. กด **ล้างตะกร้า** เมื่อต้องการเริ่มรายการใหม่

## โครงสร้างโปรเจกต์

| ไฟล์ | รายละเอียด |
|---|---|
| `index.html` | หน้าเว็บหลัก รวม HTML, CSS และ JavaScript ไว้ในไฟล์เดียว |
| `requirement.md` | ภาพรวม วัตถุประสงค์ ขอบเขต ผู้ใช้ และข้อจำกัดของระบบ |
| `userjourney.md` | ขั้นตอนการใช้งานของพนักงาน |
| `functional-requirement.md` | ข้อกำหนดเชิงหน้าที่ FR-01 ถึง FR-05 และเกณฑ์ตรวจรับ |

## เทคโนโลยี

- HTML
- CSS
- JavaScript
- GitHub Pages สำหรับเผยแพร่เว็บไซต์

ระบบทำงานฝั่งเบราว์เซอร์ทั้งหมด ไม่มี Backend, ฐานข้อมูล, API, CDN หรือไลบรารีที่ต้อง Build

## การเปิดทดสอบในเครื่อง

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้ทันที หรือใช้คำสั่ง:

```powershell
start index.html
```

## ตัวอย่างการทดสอบ

| การทดสอบ | ผลลัพธ์ที่คาดหวัง |
|---|---|
| เพิ่มชุดหมู 1 ครั้ง + น้ำดื่ม 1 ครั้ง | ราคารวม 219 บาท |
| เพิ่มชุดหมู 2 ครั้ง + ชุดเนื้อ 1 ครั้ง + น้ำดื่ม 3 ครั้ง | ราคารวม 707 บาท |
| กดล้างตะกร้า | ตะกร้าว่างและราคารวม 0 บาท |

## การเผยแพร่

เว็บไซต์เผยแพร่ผ่าน GitHub Pages โดยใช้:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/(root)`

เมื่อมีการ Commit และ Push ไปยัง branch `main` GitHub Pages จะ Build เว็บไซต์ใหม่โดยอัตโนมัติ

## ข้อจำกัด

- เมนูและราคาคงที่ ไม่มีหน้าจอสำหรับแก้ไขเมนู
- ไม่มีการบันทึกข้อมูลลงฐานข้อมูล และไม่เก็บตะกร้าภายหลังรีเฟรชหน้าเว็บ
- ไม่รองรับการชำระเงิน ใบเสร็จ ภาษี ส่วนลด โปรโมชัน สต๊อก หรือประวัติการขาย
