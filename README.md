# 🍜 Suki Mini POS

เว็บระบบรับออร์เดอร์แบบ Static สำหรับร้านสุกี้ขนาดเล็ก — พนักงานรับออร์เดอร์เลือกสินค้าจากเมนู
เพิ่มลงตะกร้า ดูราคารวม และสรุปยอดให้ลูกค้าได้ทันที

> **🌐 เว็บไซต์ที่เผยแพร่แล้ว:** https://yu-alt1.github.io/suki-mini-pos/

## 🛠 เทคโนโลยี

- **HTML + CSS + JavaScript ล้วน** — ไม่มี Backend, API, ฐานข้อมูล, CDN หรือไลบรารีที่ต้อง Build
- รวมทุกอย่างไว้ในไฟล์เดียว `index.html` → เปิดใช้งานได้ทันทีโดยไม่ต้องติดตั้งอะไร
- Responsive ใช้งานได้ทั้งคอมพิวเตอร์ มือถือ และแท็บเล็ต
- รองรับการควบคุมด้วยคีย์บอร์ด และประกาศค่าให้ screen reader อัตโนมัติ

## 🚢 Deploy บน GitHub Pages

เว็บนี้ deploy แบบ **Deploy from a branch** (ไม่ใช้ GitHub Actions)

1. อัปโหลดไฟล์ทั้งหมดไว้ที่ **root ของ branch `main`** (ห้ามอยู่ในโฟลเดอร์ย่อย ไม่งั้นจะขึ้น 404)
2. ไปที่ repo → **Settings** → **Code and automation** → **Pages**
3. **Build and deployment**
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. กด **Save** แล้วรอ 1–3 นาที

เมื่อแก้ไขโค้ดแล้วต้องการอัปเดตเว็บ ทำแค่:

```bash
git add .
git commit -m "ปรับปรุงโค้ด"
git push
```

Pages จะ build และเผยแพร่ใหม่ให้อัตโนมัติ
